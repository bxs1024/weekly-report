## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与动作类型

先用一句话确认「谁，在什么时候，做了什么，处于宣布、测试、上线、完成还是复盘的哪个阶段」。然后从以下 6 类中选择最贴近的一类：

- `policy`：政策、监管、牌照、合规、政府层面的资金或战略
- `product`：产品发布、重大功能更新、平台开放、基础设施上线
- `funding`：融资、投资、估值、IPO、并购
- `earnings`：财报、营收利润变化、指引调整
- `expansion`：市场进入、区域扩张、合作生态、渠道与供应链布局
- `hiring`：招聘、组织调整、裁员、关键人事

### 二、按以下五轴独立打 0–10 整数分

1. `substance` 实质份量：它在行业时间线上是节点级变化、本月值得知道的事，还是当天脚注。不要把「容易理解」重复算进这一轴。
2. `increment` 信息增量：材料带来了多少明确的新认知，而不是标题看起来有多新。新的量化结果、新的区域动作、新的合作关系、新的约束条件才是增量。
3. `evidence` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方公告足以证明「宣布、上线、涨价、开源」这一动作，但不能自动证明宣传中的效果。
4. `actionability` BD 行动性：读者能否据此立刻做点什么——建立联系、评估进入、调整渠道、跟进采购、预判竞争。纯宏观评论和仅资本叙事的这一轴低是正常的，但不应反过来抹掉 substance。
5. `reach` 区域共振：这条事件影响的区域与赛道，和本站重点观察的非中美市场（东南亚、南亚、中东、拉美、非洲、欧洲、日韩等）重合度有多高，涉及多少可识别的参与方。

## 品味规则

### 必须正常评价的价值

- 明确的区域性政策变化，且对行业参与方的经营条件有实际约束或放开。
- 产品、平台或基础设施在非中美市场正式落地，带来明确的能力边界、开放入口或价格变化。
- 有明确金额、明确参与方、明确用途的资本动作，特别是改变区域竞争格局的。
- 财报中出现的结构性转向（由盈转亏、增速断崖、指引大幅调整），不只是常规季度波动。
- 市场进入、渠道铺设、生态合作中给出具体对象、规模或时间的动作。
- 组织行为的量化信号：成规模的招聘、裁员、关键岗位变动，且指向明确的战略调整。

### 必须压住的噪声

- 客户案例、部署合作、使用体验分享，若没有明确任务、规模、成本、时间或可迁移方法，`substance ≤ 4`。
- 例行小版本、常规功能、语言或地区补齐、普通缺陷修复、窄 SDK 支持，`substance ≤ 3`。
- 营销软文、活动推广、招聘广告、限免促销、模糊路线图，`substance ≤ 2`。
- 只有预告、传闻或「即将推出」，没有实质参数与可验证内容，`increment ≤ 3` 且 `evidence ≤ 4`。
- 单个用户的个人体验、单一内部基准、只有形容词没有数据的效果描述，`increment ≤ 3` 且 `substance ≤ 4`。
- 新闻摘要合集、早报、周报、多事件打包且没有单一焦点，`substance ≤ 3`。
- 厂商绑定式的教程或 how-to，没有脱离该平台仍成立的通用方法，`substance ≤ 3`。
- 纯资本叙事：只讲融资、估值、机构进入，没有任何已兑现的经营后果，`actionability ≤ 3`。
- 宏大观点、行业判断、趋势预测，若没有新事实、新因果或可复用框架，`substance ≤ 3`。

## 事件口径校正

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否转述，误当成事件本身的价值。若与前文的直觉判断冲突，以本节为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给「这篇文章写得怎么样」打分。
2. 广泛的可用性变化本身就是实质变化。一个被大量使用的产品把明确的能力升级正式推给用户，这是现实影响的变化；即使材料是短引用，也不能按「个人体验」或「普通转发」压低 `substance`、`increment`、`reach`。
3. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。
4. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、单一内部基准或厂商营销制造事件价值。只有正文支持的新事实、可行动变化或可迁移方法进入五轴。
5. 本条已经通过机械闸门，不要再判断它是否属于本站范围，也不要因为「领域不熟悉」而给中间分。
