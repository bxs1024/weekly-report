# 给 Agent 的接入说明

本站（全球互联网百晓生）面向出海 BD、战略与投资从业者，持续观察非中美市场的互联网产业动态。以下说明如何把本站内容接入你的 Agent 或工具链。

## 推荐入口

| 入口 | 地址 | 适合 |
|---|---|---|
| RSS 事件流 | `/feed.xml` | 定期拉取当天合格事件，最稳定 |
| 站点首页 | `/` | 阅读日报、查看分层与历史导航 |
| llms.txt | `/llms.txt` | 一次性了解站点内容与口径 |

## RSS 说明

- 格式：Atom XML（`application/atom+xml`）
- 内容：当天通过最终事件资格的全部事件，不含聚合类补漏来源
- 字段：每条 entry 含 `title`（中文标题）、`link`（原文链接）、`published`（事件归属日期）、`summary`（原题 + 内容概要 + 点评 + 标签）

建议做法：
1. 优先使用 `published` 而不是 `updated` 判断事件归属日——生成时间与事件日期可能不同。
2. 把 `summary` 里的「内容概要」当作事实层，把「点评」当作观点层，不要混用。
3. 需要追溯原始事实时，跟 `link` 回原文；站内摘要为编辑层加工结果。

## 请求约定

- 建议使用可识别的 User-Agent（包含项目名与联系方式），便于在异常流量时联系你。
- 请控制频率，建议不低于 30 分钟一次；本站内容每天更新两次（北京时间 02:00 早采、09:00 补采）。
- 页面为静态生成，可直接抓取，不需要模拟登录。

## 内容口径（用于判断相关性）

事件进入本站前经过四道判断：观察范围、互联网相关度、事件价值、行动性。

需要知道的边界：
- **在范围内**：互联网平台、AI 与云基础设施、SaaS、支付与金融科技、电商、数据基础设施、企业软件
- **不在范围内**：军工国防、生物制药与疗法研发、纯医疗器械、纯航天与卫星影像、泛工业科技融资

评分只用于排序，不用于过滤。因此你拿到的事件列表已经是资格筛选后的结果，不需要再按分数二次过滤。

## 已知限制

- 站内不展示全文，只展示摘要与原文链接（来源明确允许时除外）。
- 聚合类补漏来源（新闻聚合器）不进 RSS，只留在站内作为补漏证据。
- 周报与月报在原站点页面查看，暂不单独提供接口。
- 数据按日期归档完整保留，但 RSS 只推送当天合格事件，历史数据请直接用站点页面。
